 # Rangkuman Sesi: Cara Pakai fcc-claude, Plugin PRAW HAX, OpenCode & Langkah Instalasi\\n \\n Tanggal: 2025-10-28\\n \\n ## Point Penting\\n \\n ### 1) Free Claude Code Ecosystem\\n - \*\*Agents\*\*: Claude Code, Codex, OpenCode (gratis), Pi, Cline\\n - \*\*Proxy\*\*: \`fcc-server\` jalan di \`http://127.0.0.1:8082\`, admin UI di \`http://127.0.0.1:8082/admin\`\\n - \*\*Endpoint\*\*: \`/claude\`, \`/codex\`, \`/opencode\`, \`/pi\`, \`/cline\` (format OpenAI-compatible \`/v1/chat/completions\`)\\n - \*\*OpenCode\*\*: paling praktis (gratis, tanpa API key)\\n - \*\*Config\*\*: \`~/.fcc/.env\`, auth di \`~/.fcc/auth/\`, log di \`~/.fcc/logs/\`\\n \\n ### 2) Plugin HAX via PRAW (haxtheweb/praw)\\n Repo: https://github.com/haxtheweb/praw\\n \\n Marketplace & plugin:\\n \`\`\`bash\\n /plugin marketplace add haxtheweb/praw\\n /plugin install hax-onboarding@haxtheweb\\n \`\`\`\\n \\n Catatan:\\n - Slash command \`/plugin\` adalah fitur \*\*Claude Code CLI interaktif\*\*. Tidak bisa dipanggil lewat \`fcc-server\` HTTP proxy.\\n - Ada script onboarding: \`curl -fsSL https://raw.githubusercontent.com/haxtheweb/praw/main/hax-onboarding.sh | bash\`\\n - Plugin \`hax-onboarding\` auto-install HAX CLI, bawa skill pengetahuan, dan sediakan slash command (quickstart, site, webcomponent, audit, serve, publish).\\n \\n ### 3) OpenCode (via fcc-server / standalone)\\n - \*\*Standalone\*\*: \`opencode run "task"\` atau \`opencode\` interaktif\\n - \*\*Via proxy\*\*:\\n \`\`\`bash\\n curl -X POST http://localhost:8082/opencode/v1/chat/completions \\\\n  -H "Content-Type: application/json" \\\\n  -d '{"model": "opencode/free", "messages": \[{"role": "user", "content": "Halo"}\]}'\\n \`\`\`\\n - Cocok untuk HAX/webcomponent tanpa perlu API key.\\n \\n ## Langkah Praktis (Rekomendasi)\\n \\n ### Opsi A: Install plugin langsung di Claude Code (paling benar untuk /plugin)\\n \`\`\`bash\\n # Cek claude\\n claude --version # v2.1.267 terinstall\\n \\n # Jalankan Claude Code interaktif\\n claude\\n \\n # Di dalam Claude Code:\\n /plugin marketplace add haxtheweb/praw\\n /plugin install hax-onboarding@haxtheweb\\n # atau dari folder lokal:\\n /plugin install hax-onboarding@folder:/opt/data/home/Documents/git/haxtheweb/\\n \`\`\`\\n \\n ### Opsi B: Start fcc-server untuk routing multi-agent\\n \`\`\`bash\\n # Jalankan background\\n nohup fcc-server > ~/.fcc/server.log 2>&1 &\\n # Cek\\n curl http://127.0.0.1:8082/health\\n # Admin UI: http://127.0.0.1:8082/admin\\n \`\`\`\\n \\n ### Opsi C: Onboarding HAX cepat (script)\\n \`\`\`bash\\n curl -fsSL https://raw.githubusercontent.com/haxtheweb/praw/main/hax-onboarding.sh | bash\\n \`\`\`\\n \\n ## Rekomendasi\\n 1. \*\*Untuk plugin marketplace/install\*\* → pakai \*\*Claude Code CLI langsung\*\* (interaktif). Jangan lewat fcc-server.\\n 2. \*\*Untuk orkestrasi paralel / routing ke banyak agent\*\* → pakai \*\*fcc-server\*\*.\\n 3. \*\*Untuk coba-coba tanpa biaya\*\* → pakai \*\*OpenCode\*\* (standalone atau via proxy).\\n 4. \*\*Untuk onboarding HAX end-to-end\*\* → jalankan \*\*hax-onboarding.sh\*\* atau plugin \`hax-onboarding\` di Claude Code.\\n \\n ## Troubleshooting Singkat\\n - \`tmux/screen\` tidak wajib, cukup \`claude\` langsung di terminal\\n - Kalau plugin install dari folder: pastikan path benar\\n - Admin UI fcc hanya localhost (butuh SSH tunnel kalau remote)\\n
