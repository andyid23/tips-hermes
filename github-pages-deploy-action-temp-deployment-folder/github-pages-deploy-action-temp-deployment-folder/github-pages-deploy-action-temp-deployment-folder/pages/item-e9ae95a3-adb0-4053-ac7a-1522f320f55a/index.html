Apa itu Hermes Agent?

Hermes Agent adalah asisten AI yang dapat dieksekusi di terminal, dengan akses ke tools untuk browsing, coding, manajemen file, dan banyak lagi. Situs ini berisi tips untuk memaksimalkannya.

Kategori Tips

  • Konfigurasi — setting profile, skills, dan memory
  • Workflow — delegasi, paralelisasi, dan best practices
  • Infrastruktur — Drupal, HAXCMS, dan self-hosted services
  • Otomatisasi — cron job, scheduled tasks, dan scripting
